# TEMAS Legacy Archive (v0.8.0 - March 2023)

This directory preserves the historical artifacts and prototype code created during the initial response to the February 2023 Kahramanmaraş earthquake sequence in Turkey and Syria:

- **`app-updater.py`**: The original monolithic batch scraper and Folium map compiler.
- **`tuner_all-in-one_koeri_data.ipynb`**: Original exploratory data analysis notebook.
- **`web/`**: Legacy static HTML dumps (`map_bubble_koeri.html`, `table_interact_koeri.html`, Bootstrap iframe index).
- **`nginx.conf`**, **`entrypoint-wrapper.sh`**, **`mycrontab`**: Original container configuration experiments.
- **`testlab/`**: Historical experimental scripts and CSV logs.

Active production code for TEMAS 2.0 is maintained in `backend/` (FastAPI) and `frontend/` (Leaflet Single Page Application).
